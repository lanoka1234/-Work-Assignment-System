# Work Assignment System

This project is a Flask and MySQL-based API designed to manage work assignments between people and jobs.

## Features
- Add people and jobs
- Create assignments
- Prevent overlapping job assignments
- Update assignments using PUT requests
- Delete jobs and related assignments
- Retrieve assigned jobs and workers

## Technologies Used
- Python
- Flask
- MySQL
- GitHub

## API Endpoints
- POST /person
- POST /job
- POST /assignment
- GET /jobs
- DELETE /job/<job_id>
- PUT /assignment/<job_id>

## Purpose
This project was created as part of a CIS coursework assignment focused on backend API development and database integration.
